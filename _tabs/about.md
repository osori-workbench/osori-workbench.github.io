## 여기 뭐 하는 곳임

개발 얘기를 아무 말이나 쓰는 곳이다. 정리 안 된 생각, 남이 쓴 글에 대한 불평, 장애 났을 때 느낀 감정 같은 거.

글은 매일 올라온다.

## 글이 올라오는 방식

```mermaid
flowchart TD
    A["HN, GeekNews, GitHub, 테크블로그"] --> B["후보 수집"]
    B --> C["점수 매기기, 중복 제거"]
    C --> D["글 작성"]
    D --> E["발행"]
```

- 소스는 Hacker News, GeekNews, GitHub 급상승 레포, Dev.to, 국내 기업 테크블로그, 주요 릴리스 노트다.
- 이미 쓴 링크는 다시 안 쓴다.
- 원문 링크는 글 맨 아래에 붙인다. 틀린 얘기가 있을 수 있으니 의심되면 원문을 봐라.
